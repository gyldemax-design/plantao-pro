PLANTÃO PRO — INSTALAÇÃO COMO APLICATIVO (PWA)

1. Descompacte este arquivo ZIP em uma pasta.
2. Publique a pasta em qualquer hospedagem HTTPS gratuita:
   - Netlify Drop: acesse https://app.netlify.com/drop e arraste a pasta.
   - Ou Vercel / GitHub Pages / Cloudflare Pages.
3. Abra o link gerado no navegador do celular:
   - Android (Chrome): toque no menu (⋮) -> "Instalar aplicativo" ou "Adicionar à tela inicial".
   - iPhone (Safari): toque em Compartilhar (↑) -> "Adicionar à Tela de Início".
   O aplicativo aparecerá na tela inicial com o símbolo do Instituto Códice em azul-marinho executivo e funcionará inclusive offline.
